# 🚀 StackCraft

StackCraft est une application **MERN** (MongoDB, Express.js, React.js, Node.js) qui génère automatiquement des idées de projets logiciels en fonction du métier et de la stack technologique choisie par l'utilisateur, grâce à **Mistral AI**.

L'application met en œuvre des pratiques modernes de développement et de déploiement :

- 🤖 Génération intelligente d'idées de projets avec **Mistral AI**
- ⚛️ Interface utilisateur développée avec **React**
- 🟢 Backend REST construit avec **Node.js** et **Express**
- 🍃 Base de données **MongoDB**
- 🐳 Conteneurisation avec **Docker**
- 🔄 Intégration et déploiement continus (**CI/CD**) avec **GitHub Actions**
- ☸️ Déploiement sur **Kubernetes (Minikube)**
- 🚀 Déploiement GitOps automatisé avec **Argo CD**

## 🛠️ Technologies utilisées

- React.js
- Node.js
- Express.js
- MongoDB
- Mistral AI
- Docker
- GitHub Actions
- Kubernetes (Minikube)
- Argo CD
- Git

## ✨ Fonctionnalités

- Génération automatique d'idées de projets selon un métier.
- Sélection d'une stack technologique adaptée.
- Suggestions détaillées de projets grâce à l'IA.
- Architecture full-stack MERN.
- Déploiement automatisé avec une pipeline CI/CD.
- Déploiement GitOps sur Kubernetes avec Argo CD.
